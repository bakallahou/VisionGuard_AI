#  VisionGuard AI

##  AI Smart Attendance & Security System

VisionGuard AI is an advanced biometric attendance and security platform based on Artificial Intelligence and Computer Vision.

The system uses real-time facial recognition, anti-spoofing security, AI analytics, automated reporting, and voice assistance to modernize attendance management and intelligent surveillance.

---

#  Features

##  AI Face Recognition
- Real-time face detection
- ArcFace facial recognition
- Confidence score calculation
- Unknown person detection

##  Security System
- Anti-spoofing protection
- Security voice alerts
- Unauthorized person detection
- Smart monitoring system

##  Smart Dashboard
- Cyberpunk Glassmorphism UI
- Real-time analytics
- Attendance statistics
- Student ranking system
- Live activity feed

##  Reporting System
- PDF report generation
- Excel report generation
- Automatic email sending

##  Authentication
- Secure login/logout system
- Admin access control

## 🎤 AI Voice Assistant
- Voice welcome system
- Security warning alerts

#  Installation

## Clone Repository

```bash
git clone https://github.com/bakallahou/VisionGuard_AI.git
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Application

```bash
streamlit run main.py
```
